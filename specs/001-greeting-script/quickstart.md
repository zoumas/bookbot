# Quickstart: Greeting Script

## Prerequisites

- Python 3 installed (`python3 --version`)

## Run

```bash
python3 main.py
```

## Expected Outcome

Console prints exactly:

```
greetings boots
```

with no other output, and exits with status 0.

## Validation

- Manual: run the command above and visually confirm the output.
- Automated: `bootdev run <lesson-id>` (and `-s` to submit) against this
  lesson's check.
